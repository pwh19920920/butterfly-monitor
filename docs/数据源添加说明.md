# 数据源添加说明

本文说明如何在 Butterfly Monitor 中配置**被监控数据源**，以及各类型的连接字段、`Command` 写法与注意事项。

相关代码：

- 类型常量：`backend/internal/domain/entity/monitor_database.go`
- 前端枚举：`frontend/src/services/ant-design-pro/enum.ts`
- Handler 注册：`backend/internal/starter/starter.go`

平台**自身元库**仍是 MySQL（GORM），与下文「被监控数据源」不是同一概念。  
采集结果写入本平台**时序存储**（`TimeSeriesStore` 抽象，`timeseries.backend` 可选 `victoriaMetrics`（默认）或 `tdengine`），再走样本基线与告警；对 Prometheus / VictoriaMetrics / TDengine / OpenSearch / Elasticsearch **只读查询、不写对方**。

---

## 1. 通用流程

1. 进入管理端 **数据源** 页 → **新建**。
2. 选择类型，填写名称、地址、账号密码、库名（按类型）、附加参数。
3. 保存前系统会按类型调用 `TestConnect`；失败不落库。
4. 密码 DES-CBC + 随机盐加密存储；修改时密码留空表示沿用旧密码。
5. 后台约 **每分钟** 扫描建连，新数据源最多 1 分钟后可被 Database 任务使用；此前可能报 `dbMap is not contain <id>`。
6. 创建 **监控任务**（TaskType=Database），关联该 `databaseId`，填写 `Command` 与周期。

### 1.1 连接字段（`t_monitor_database`）

| 字段 | 含义 |
|------|------|
| `name` | 展示名称 |
| `type` | 数据源类型枚举，见下表 |
| `url` | 地址，多数为 `host:port` |
| `database` | 库名 / 默认 index（部分类型可空） |
| `username` / `password` | 账号；密码加密落库 |
| `params` | 附加连接参数（DSN query / URL query / 自定义 key=value） |

### 1.2 任务侧

| 任务配置 | 说明 |
|----------|------|
| TaskType | `Database`（1） |
| DataType | `1` 正常查询（单值 float）；`2` 聚合查询（多行分组） |
| Command | 见各类型说明（SQL / 管道 / PromQL / DSL…） |
| ExecParams | 至少含 `databaseId`；单值任务通常还需 `defaultValue`（无结果回落） |

## 2. 类型总表

| 值 | 类型 | Handler | Command 语义 | 默认端口 | 只读 |
|----|------|---------|--------------|----------|------|
| 1 | Mongo | `DatabaseMongoHandler` | Extended JSON 聚合管道 | — | 采集只读语义 |
| 2 | Mysql | `DatabaseMysqlHandler` | SQL | 3306（惯例） | SQL 校验 + 会话只读 |
| 3 | PostgreSQL | `DatabasePostgresHandler` | SQL | 5432 | 会话 `default_transaction_read_only` |
| 4 | MariaDB | 复用 Mysql | SQL | 3306 | 同 Mysql |
| 5 | TiDB | 复用 Mysql | SQL | 4000 等 | 同 Mysql |
| 6 | OceanBase | 复用 Mysql | SQL | 2881 等 | **仅 MySQL 模式** |
| 7 | Doris | 复用 Mysql | SQL | FE 9030 等 | 同 Mysql |
| 8 | StarRocks | 复用 Mysql | SQL | FE 9030 等 | 同 Mysql |
| 9 | ClickHouse | `DatabaseClickHouseHandler` | SQL | **9000** 原生 | `readonly=1` + SQL 校验 |
| 10 | Prometheus | `DatabasePrometheusHandler` | PromQL | **9090** | **仅查询 API** |
| 11 | OpenSearch | `DatabaseOpenSearchHandler` | `_search` / `_count` / SQL | **9200** | **仅查询 API** |
| 12 | Elasticsearch | 复用 OpenSearch | 同 11 | **9200** | **仅查询 API** |
| 13 | VictoriaMetrics | 复用 Prometheus handler | MetricsQL/PromQL | **8428** | **仅查询 API** |
| 14 | TDengine | `DatabaseTDengineHandler` | REST SQL | **6041** | **仅查询 API** |

实现分组：

1. **MySQL 协议族**（2/4/5/6/7/8）→ 同一套 mysql 驱动与 DSN  
2. **Mongo**（1）  
3. **PostgreSQL**（3）  
4. **ClickHouse**（9）  
5. **Prometheus / VictoriaMetrics**（10/13）共用 handler（默认端口不同）  
6. **OpenSearch / Elasticsearch**（11/12）共用 handler  
7. **TDengine**（14）REST SQL 只读

云厂商 MySQL 兼容实例（如部分 PolarDB / GaussDB MySQL 模式）一般直接选 **Mysql**，无需单独类型。

## 3. MySQL 协议族（2 / 4 / 5 / 6 / 7 / 8）

适用于：Mysql、MariaDB、TiDB、OceanBase（**MySQL 模式**）、Doris、StarRocks。

### 连接

| 字段 | 填写 |
|------|------|
| `url` | `host:port`（Doris/StarRocks 填 **FE 的 MySQL 协议端口**，常见 9030） |
| `database` | 库名 |
| `params` | DSN `?` 后查询串；留空默认 `charset=utf8mb4&parseTime=True&loc=Local` |

底层 DSN 形如：

```text
user:pass@tcp(host:port)/dbname?charset=utf8mb4&parseTime=True&loc=Local
```

### Command

- **单值**：返回一列数值的只读 SQL，例如：

```sql
SELECT COUNT(*) FROM orders WHERE status = 'paid'
```

- **分组聚合**：带维度列 + 数值列，例如：

```sql
SELECT region, COUNT(*) AS cnt FROM orders GROUP BY region
```

允许前缀：`SELECT` / `SHOW` / `WITH` / `DESC` / `DESCRIBE` / `EXPLAIN`。  
禁止：多语句 `;`、写操作、`INTO`、`FOR UPDATE` 等。

### 注意

- **OceanBase** 仅支持 MySQL 模式；Oracle 模式不要选 type=6。  
- TiDB / Doris / StarRocks 端口以各环境文档为准，类型只决定 handler，不替你改端口。

## 4. PostgreSQL（3）

### 连接

| 字段 | 填写 |
|------|------|
| `url` | `host:port`，无端口默认 **5432** |
| `database` | 库名 |
| `params` | libpq 风格，如 `sslmode=disable` 或 `sslmode=require TimeZone=Asia/Shanghai`（空格会规范成 `&`）；留空默认 `sslmode=disable` |

DSN 形如：`postgres://user:pass@host:port/db?sslmode=disable`（密码经 URL 编码）。

### Command

与 MySQL 族相同：只读 SQL；单值 / `GROUP BY` 多行。  
会话级只读：`SET default_transaction_read_only = on/off`。

示例：

```sql
SELECT COUNT(*)::float8 FROM pg_stat_activity
```

```sql
SELECT state, COUNT(*)::float8 AS cnt FROM pg_stat_activity GROUP BY state
```

## 5. ClickHouse（9）

### 连接

| 字段 | 填写 |
|------|------|
| `url` | `host:port`，**默认 9000（原生协议）**，不是 HTTP 8123 |
| `database` | 库名 |
| `params` | 如 `dial_timeout=10s&readonly=1`；留空即该默认 |

DSN 形如：`clickhouse://user:pass@host:9000/default?dial_timeout=10s&readonly=1`。

### Command

只读 SQL。`count()` 等常返回 UInt64，handler 会做数值转换。

```sql
SELECT count() FROM system.processes
```

```sql
SELECT query_kind, count() AS cnt FROM system.processes GROUP BY query_kind
```

## 6. MongoDB（1）

### 连接

| 字段 | 填写 |
|------|------|
| `url` | host 或 `host:port` |
| `database` | database name |
| `params` | URI `?` 后，如 `connectTimeoutMS=5000` |

URI 形如：`mongodb://[user:pass@]host[:port]/db[?params]`。

### Command

Extended JSON **聚合管道**（任务表单可配集合名等 mongo 专用项）：

```json
{"collection":"orders","pipeline":[{"$match":{"status":"paid"}},{"$count":"n"}]}
```

或纯管道数组（默认 collection=`metrics`）：

```json
[{"$group":{"_id":null,"value":{"$sum":"$amount"}}}]
```

- **单值**：取首文档第一个数值字段（优先 `value` / `n` / `count` 等）。  
- **多行**：每个输出文档映射为一行。  
- 管道末若无 `$limit` 会自动追加行数上限，防 OOM。

## 7. Prometheus（10）— 只读

**不会** Remote Write / Pushgateway，只调对方查询 API。

### 连接

| 字段 | 填写 |
|------|------|
| `url` | `host:port`，默认 **9090** |
| `database` | **可留空** |
| `username`/`password` | 可选 Basic Auth |
| `params` | `scheme=http|https`、`path_prefix=/prometheus`、`timeout=30s` |

探活：`/-/healthy`，失败可降级 buildinfo。

### Command

完整 **PromQL**（即时查询 `/api/v1/query`）：

```promql
sum(rate(http_requests_total{job="api"}[1m]))
```

分组多行（每个 series 一行，列=labels + `value`）：

```promql
sum by (code) (rate(http_requests_total{job="api"}[1m]))
```

单值任务若返回多个 series，默认取第一个；建议在 PromQL 侧 `sum`/`avg` 收敛。

---

## 8. VictoriaMetrics（13）— 只读

与 Prometheus **共用** `DatabasePrometheusHandler`（API 兼容），**不** remote write / import。

### 连接

| 字段 | 填写 |
|------|------|
| `url` | `host:port`，默认 **8428** |
| `database` | **可留空** |
| `username`/`password` | 可选 Basic Auth |
| `params` | `scheme=http|https`、`path_prefix`、`timeout=30s` |

`Command` 写完整 **PromQL / MetricsQL**，语义同 Prometheus 节。

> 注意：这是**被监控数据源**，与平台 `timeseries.backend=victoriaMetrics`（采集结果写入）可以是不同实例。

---

## 9. TDengine（14）— 只读

`DatabaseTDengineHandler`，经 taosAdapter **REST `/rest/sql`** 查询；**不**建库建表、**不** INSERT。

### 连接

| 字段 | 填写 |
|------|------|
| `url` | `host:port`，默认 **6041**（taosAdapter） |
| `database` | 业务库名（可空则仅集群级 SQL，如 `SHOW DATABASES`） |
| `username`/`password` | 默认账号 `root`；密码按环境填写 |
| `params` | `scheme=http|https`、`timeout=30s` |

探活：`SHOW DATABASES`。

### Command

只读 SQL（允许 `SELECT` / `SHOW` / `DESC` / `DESCRIBE` / `EXPLAIN`；禁止 `;` 多语句与 DML/DDL）：

```sql
SELECT AVG(val) FROM metrics WHERE ts > now - 1h
```

- **单值**：取首行第一个可解析为 float 的列。  
- **多行**：按 `column_meta` 列名映射为行（可用于聚合任务 `labelColumns` / `valueColumns`）。

> 注意：这是**被监控数据源**，与平台 `timeseries.backend=tdengine`（采集结果写入）可以是不同实例。

---

## 10. OpenSearch（11）/ Elasticsearch（12）— 只读

二者**共用** `DatabaseOpenSearchHandler`，**不** bulk/index/update/delete。

### 连接

| 字段 | 填写 |
|------|------|
| `url` | `host:port`，默认 **9200** |
| `database` | **默认 index**（可空则走集群级路径） |
| `username`/`password` | 可选 Basic Auth |
| `params` | `scheme`、`path_prefix`、`timeout`、**`api=search\|count\|sql`**（默认 `search`） |

### Command（由 `params.api` 决定）

#### api=search（默认）

完整 `_search` JSON。单值优先 metric 聚合 `value`，否则 `hits.total`：

```json
{"size":0,"query":{"match_all":{}},"aggs":{"c":{"value_count":{"field":"_id"}}}}
```

分组：terms 等 buckets 展开为多行，常见列 `key` / `doc_count` / `value` / 子 metric 名。

#### api=count

Command 可空，或带 query JSON；结果为 `count`。

#### api=sql

```sql
SELECT count(*) FROM my-index
```

优先 `POST /_plugins/_sql`（OpenSearch），失败回退 Elasticsearch `POST /_sql`。  
禁止 `INSERT/UPDATE/DELETE/DROP/...` 与多语句。

## 11. 单值 vs 分组聚合

| DataType | 行为 | 各源要点 |
|----------|------|----------|
| 正常查询（1） | 得到一个 `float64` 写入实时指标 | SQL 一列；Mongo 首文档数值；Prom 一个 vector/scalar 点；OS/ES metric 或 total |
| 聚合查询（2） | 多行 → 按 label/value 列写入多维序列 | SQL `GROUP BY`；Mongo 多文档；Prom 多 series；OS/ES terms buckets 或 SQL 多行 |

各 handler 对多行有统一行数上限（约 `MaxAggregateRows=10000`），防 OOM。

---

## 12. 安全与权限建议

1. 被监控库账号尽量 **只读**（SELECT / 查询 API）。  
2. Prometheus / VictoriaMetrics / TDengine / OpenSearch / ES：**不要** 给写权限（remote write / INSERT / 建表）。  
3. SQL 类另有静态校验与会话/连接级只读，仍不能替代账号权限。  
4. 密码仅前端创建/修改时提交明文，落库密文；接口查询不回传密码与盐。

## 13. 常见问题

**Q：新建数据源后任务立刻报找不到连接？**  
A：最多等约 1 分钟建连；或重启后等刷新协程跑完。

**Q：改了地址/密码不生效？**  
A：修改会摘掉旧连接，下一轮刷新按新配置重建。

**Q：ClickHouse 连 8123 失败？**  
A：默认实现走**原生协议 9000**。HTTP 端口需按 clickhouse-go 文档在 params 中显式配置，不在默认路径内。

**Q：OceanBase / 国产库选哪个？**  
A：MySQL 协议选 **OceanBase(6)** 或直接 **Mysql(2)**；Oracle 模式目前不支持。

**Q：OpenSearch 和 Elasticsearch 有何区别？**  
A：产品类型不同（11 vs 12），实现相同。SQL 路径会先试 OS 插件再回退 ES。

**Q：Prometheus/VM/TDengine/OS/ES 会污染对方数据吗？**  
A：**不会写入**；只查询，结果进本平台时序库（`timeseries.backend`）。

**Q：VictoriaMetrics 和平台自身时序后端是一回事吗？**  
A：**不是。** type=13 是被监控数据源（只读采对方）；`timeseries.backend=victoriaMetrics` 是采集结果写入目标。可指向不同实例。

**Q：TDengine 数据源和平台 tdengine 后端有何区别？**  
A：type=14 只读 REST SQL 采外部库；平台 `timeseries.backend=tdengine` 会建超级表并写入样本。二者 handler 不同。

## 14. 扩展新类型（开发）

1. `DataSourceTypeXxx` 常量（避免占用 0）。  
2. 实现 `domain/handler.DatabaseHandler` 五方法，或协议兼容则**复用**现有 handler。  
3. `starter.registerHandlers` 注册。  
4. 前端 `DatabaseTypeEnum` + 数据源页 params 提示。  
5. 更新本文档、`README` 技术栈、`功能文档` §3.2。

- SQL 独立方言：参考 `database_postgres_handler.go` / `database_clickhouse_handler.go`  
- HTTP 只读：参考 `database_prometheus_handler.go` / `database_opensearch_handler.go`  
- MySQL 协议兼容：只加常量并注册同一 `DatabaseMysqlHandler`
